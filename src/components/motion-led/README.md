# Continuous opening motion film

[Issue #24](https://github.com/Special-Rapid/snkisk.com/issues/24) / [PR #25](https://github.com/Special-Rapid/snkisk.com/pull/25).

The opening is an automatic, silent, full-viewport 2D product film, followed by the ordinary scrolling project site. The first PR25 version (`6a42b70`) was rejected by the owner: a static heading, image-and-caption carousel and moving progress dot did not address the original slide-like motion. Its old model passes are not acceptance of this version. The visual basis remains the original saturated colour fields, large condensed typography and routing/block/palette compositions. The completed reference Remotion project is read-only and is never embedded as the website.

`timeline.ts` owns one elapsed-time clock model. `FilmArt.tsx` always renders the same foreground object and four quarter pieces; no keyed chapter replacement or autonomous scene animation is used. The route capsule contracts and travels to its endpoint, expands into the Legitils disc, squares and splits into Minecraft blocks, then each block elongates into one of the four original Hensyoku Mate PNG screens. Text is revealed or displaced by these transitions. A limited 2D pan/scale follows the expanding object; there is no 3D camera or perspective. Film typography roles and authored brand colours live in `FILM` / `FILM_TYPE`; these graphic colours remain authored illustrations in both UI themes. Utility controls and Home use the semantic CSS tokens in `App.module.css`.

The 12.95-second edit assigns different durations to route travel, disc motion, block printing, palette reading and the final handoff. Each composition holds still for approximately 0.8–1.0 seconds after its motion has settled; `READING_HOLDS` records those authored intervals separately from transitions. A monotone, continuously differentiable beat map retains the authored geometry while changing scene durations independently. Long travel, settling and outgoing type have distinct zero-end-velocity profiles; the disc and block assembly also ease their sinusoidal motion at both ends. Reading time, world-space velocity and the actual rendered film should be reviewed together; the numbers alone do not establish perceptual quality.

In landscape, the first real quarter lifts into a dedicated upper print lane before any Minecraft type appears. It sweeps left, returns along that lane, then docks in the right assembly area. The type clip and connecting trace follow its real projected edge; the completed trail stays visible during the return. The left type area and right assembly area remain separate. Portrait uses its lower print lane below the type. Verify the entire sweep, return and docking against all four rotated pieces, including short landscape and the portrait threshold; changing which layer hides the other is not a collision fix.

Graphic type scales with the available landscape height, while the route address keeps its authored label size. Compact portrait stages scale the Minecraft type and blocks, and the palette type, independently to preserve the separation of their rows. The final landscape PNG width is capped by both its authored width and the available height; its lower row and the two headline baselines reserve separate vertical regions. Original PNG aspect ratios remain unchanged. Verify the complete film in short landscape as well as the narrative transition; a successful transition alone does not establish final-scene fit.

The final handoff retains the existing fixed cream/coral/blue plane. Only its clip changes, driven by the same timeline (11.7–12.95 seconds). It is used at the site handoff, not to conceal every project change. The original Home hero, four real project sections, seven original media URLs, safety notice and shortcut map remain available after completion or Skip. The four released PNG files are reused without recompression, upload or changed aspect ratio. No gameplay footage, notification data, metrics, release status or backend behavior is fabricated.

`BrandMark.tsx` is the existing four-leaf mark translated from the editable polygons and gradients in `PortfolioSequence.module.css` (original source around lines 671–714). Its inline SVG uses a 52×52 coordinate square, four separated leaves and the exact existing gradient stops. No raster derivative is needed for this web SVG consumer. The legacy sequence and logo files remain intact.

The film fills its viewport without a bottom control bar. A small, labelled pause/resume icon and a visible Skip control remain keyboard and pointer accessible above the film; Skip reveals and focuses the real project index from the first frame. The same playback controls remain mounted across the Home handoff. Home's compact menu contains the four direct project links and display/language settings. Focusing that menu latches pause until explicit Resume. Pause freezes the entire narrative, geometry, background, type and final cover. Visibility/page lifecycle independently suspend elapsed time; Replay starts explicitly at zero. Reduced motion immediately reveals Home without the film or handoff, including when enabled mid-play, and disabling it never restarts automatically. Image failure cannot block the clock, controls or project information.

Japanese and English are supported, LTR. Exact/base English resolves to English; Japanese and unsupported system locales fall back to Japanese. System locale changes are observed through `languagechange`; manual selection is saved in `snkisk-site-language-v1`. Theme System/Light/Dark is saved in `snkisk-site-theme-v1`; System continuously follows `prefers-color-scheme`, manual choices override it. Storage failures retain in-memory operation. Preference updates preserve the mounted player, elapsed time and navigation context, and update copy, `lang`, `dir`, `color-scheme`, tokens and theme-color metadata without reload. The Web platform exposes no supported cross-platform native accent palette API, so native accent mapping is N/A. Static fallback/404 retain their existing separate presentation.

Run `npm run build` and `node --test tests/motion-timeline.test.mjs`. The tests check boundary geometry continuity, final handoff, media bounds/aspect and supported locale resolution; they do not prove perceptual continuity. Native browser recordings, normal-speed replay and transition start/mid/end views must also be reviewed against the original film concept. Recording instrumentation/cadence and device performance are separate evidence. Verify narrow widths, enlarged utility text, both themes/locales, System/persistence, reduced motion, pause/focus/skip, visibility/media/storage failure and all original destinations. Do not call technical/model approval the owner's visual acceptance. Ordinary preview publication is authorized; merge and production remain outside scope.
