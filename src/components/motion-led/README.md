# Motion-led project introduction

Issue: [#24](https://github.com/Special-Rapid/snkisk.com/issues/24).

The automatic, silent 14.4-second introduction applies the accepted Motion study's readable holds, brief transitions and persistent visual anchor to real project media. It does not embed that movie or reuse the earlier Go-to-Legitils prototype. A stationary title and four permanent project anchors keep the website usable from its first frame. Full descriptions, real service links, original media and the Hensyoku safety notice remain below.

`timeline.ts` is the single elapsed-time model. Four chapters use 450 ms entrances followed by still reading intervals. The same rail marker advances continuously between chapters. Text never scales or animates letter by letter. The last chapter settles into a static view; completion does not unmount content or force scrolling. Rendering updates are confined to `PortfolioIntro`; the project sections do not rerender every frame. Existing published media URLs are reused without uploads or transcoding; Hensyoku uses its four original PNGs. Missing images cannot block the clock, copy, project anchors or links.

Pause/Resume controls stop the whole clock. Focusing header preferences or project content, and focusing/clicking the project navigator, latches pause until Resume. Page visibility and page lifecycle independently suspend elapsed time. Replay starts at zero; Skip ends playback, scrolls to and focuses the permanent project index. Reduced motion starts in the static final view; enabling it mid-play finishes permanently without surprise restart. No sound is produced. There is no network submission or asynchronous retry UI.

The main site supports Japanese and English, LTR. Exact/base English resolves to English; Japanese and unsupported locales fall back to Japanese. With no saved manual preference, the system locale is observed, including `languagechange`. `snkisk-site-language-v1` persists System/ja/en. `snkisk-site-theme-v1` persists System/Light/Dark. System follows subsequent `prefers-color-scheme` changes; manual selection stops following it. Storage errors retain in-memory operation. Preference changes update mounted content, `lang`, `dir`, `color-scheme`, semantic tokens and theme-color metadata without reload or navigation. Scroll, focused controls and playback time are retained. The browser has no supported cross-platform public API for reading the native OS accent palette; accent mapping is N/A, while appearance media queries are used. Static fallback/404 keep their existing independent presentation.

The semantic tokens in `App.module.css` define page ground/ink, muted text, media ground, dividers, signal, focus, control hover, spacing, typography and radii. The project photographs retain their existing dark readability overlays; surrounding page and Hensyoku surfaces follow the selected theme.

Run `npm ci --ignore-scripts`, `npm run build`, and `node --test tests/motion-timeline.test.mjs`. Direct browser checks must also cover both locales/themes, System changes and persistence, reduced motion, pause/focus/visibility/replay/skip, 320 px and enlarged text, media failure, shortcut redirects and the four original external destinations. Tests do not establish subjective visual acceptance. To revert the proposal, revert its feature commit; the previous sequence source and existing published assets remain available. Merge and production publication require separate authorization.
