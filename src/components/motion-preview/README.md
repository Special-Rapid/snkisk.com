# Go to Legitils motion study

[Issue #22](https://github.com/Special-Rapid/snkisk.com/issues/22) tracks this isolated six-second preview. Open `/?preview=go-legitils`; other URLs keep the existing portfolio and shortcut behavior. The query entry avoids changing Pages routing or the existing 404 page. No main merge is part of preview acceptance.

A single elapsed `requestAnimationFrame` clock drives the persistent SVG line, carrier, typography and completion. No chapter remount, CSS animation, media download, timer handoff, video or new engine is involved. The carrier follows the Go route, folds into a rounded shape and settles as the center of observation rings for Legitils. The reference informs continuity, not branding or pixel fidelity.

Manual pause and directory focus both latch pause until explicit Resume. Visibility/pagehide pauses independently; returning does not override the latch. Replay explicitly resets the clock. Natural completion leaves the final frame and focus/scroll intact; Skip completes and focuses the directory heading. The directory and its real four project destinations remain mounted and usable throughout. Reduced motion hides the decorative stage immediately and completes the timeline; disabling it leaves the completed state until an explicit Replay. A focused playback button remains mounted when reduction changes. A fresh navigation starts again; back/forward cache restores the mounted state without a forced reset.

The preview supports Japanese and English. System locale resolves exact supported locale, supported base language, then Japanese fallback. System/Light/Dark and System/ja/en manual language choices use preview-specific localStorage keys; denied/unavailable storage retains an in-memory selection. System listens for appearance/language changes. Switching keeps the same DOM, clock and focus, updates document lang/dir, color-scheme and theme-color, and never reloads. Both supported locales are LTR. Standard browser appearance media queries are available; a public Web API exposing native OS dynamic accent color for the custom SVG is unavailable, so that mapping is N/A. This does not migrate preferences or localization of the existing full portfolio.

Semantic `--preview-*` tokens scope stage, controls, spacing, typography, text, line and accent colors. New controls use native buttons/selects because the existing portfolio has no playback/preference controls. No external state request occurs; async data loading/error/retry states are N/A. The bridge uses no external images/fonts for its logic; font fallback is allowed and no media load gates access or timing. Existing media and notices remain on the unchanged full site.
